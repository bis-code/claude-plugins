# bis-code Claude Code Plugins

A unified marketplace for Claude Code plugins by bis-code.

## Install

```bash
/plugin marketplace add bis-code/claude-plugins
```

This gives you access to all plugins below. Then install any plugin individually.

## Plugins

| Plugin | Description | Install |
|--------|------------|---------|
| **deep-think** | Structured reasoning with checkpointing, branching, and reflection | `/plugin install deep-think@bis-code` |
| **study-dash** | Structured learning — dashboard, Q&A logging, AI visualizations, exercises | `/plugin install study-dash@bis-code` |
| **bearclaw** | A complete user-scope Claude Code config — skills, agents, rules and hooks | `/plugin install bearclaw@bis-code` |
